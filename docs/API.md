# REST API

Base path `/api`. JSON everywhere except the PDF. Interactive OpenAPI documentation is generated by FastAPI at
**`/api/docs`** (machine-readable schema: `/api/openapi.json`).

## Errors

Every error has the same shape:

```json
{ "error": { "code": "INPUT_TOO_LONG", "message": "Your code has 512 lines. The limit is 400 lines.", "details": {"line_count": 512, "max_lines": 400} } }
```

| HTTP | code | When |
|---|---|---|
| 422 | `EMPTY_CODE` | code is empty or only whitespace |
| 422 | `INPUT_TOO_LONG` | more than `max_lines` lines or `max_chars` characters |
| 422 | `UNSUPPORTED_FILE_TYPE` | extension not `.py`, `.js`, `.mjs`, `.cjs`, `.java` |
| 422 | `UNSUPPORTED_LANGUAGE` | language not supported, or auto-detection failed |
| 422 | `BINARY_CONTENT` | NUL bytes or > 10% non-printable characters |
| 422 | `VALIDATION_ERROR` | schema errors (`details` = list of `{field, message}`) |
| 401 | `NOT_AUTHENTICATED` | login required / wrong email or password |
| 403 | `FORBIDDEN` | not admin, deactivated account, cross-site request |
| 404 | `NOT_FOUND` | unknown or expired report (also for other users' reports) |
| 409 | `EMAIL_TAKEN` | registration with an existing email |
| 409 | `REPORT_NOT_READY` | PDF or feedback before the analysis finished |
| 415 | `UNSUPPORTED_MEDIA_TYPE` | state-changing request that is not JSON (CSRF defence) |
| 429 | `RATE_LIMITED` | limit exceeded — `Retry-After` header |
| 503 | `PDF_UNAVAILABLE` | the server has no PDF library (development on Windows) |
| 500 | `INTERNAL_ERROR` | unexpected (no stack traces are returned) |

## Auth (FR14)

| Method | Path | Body | Response |
|---|---|---|---|
| POST | `/api/auth/register` | `{full_name, email, password, store_code_default?}` | 201 `UserOut`, sets the `xai_session` cookie |
| POST | `/api/auth/login` | `{email, password}` | 200 `UserOut`, sets the cookie |
| POST | `/api/auth/logout` | — | 204, clears the cookie |
| GET | `/api/auth/me` | — | `UserOut` or 401 |
| PATCH | `/api/auth/me` | `{full_name?, store_code_default?}` | `UserOut` |

`UserOut = {user_id, full_name, email, role, store_code_default, created_at}`. Passwords: 8–128 characters with
at least one letter and one digit. Limit: 10 requests per 15 minutes per IP.

## Analyses (FR1–FR13)

| Method | Path | Auth | Description |
|---|---|---|---|
| POST | `/api/analyses` | optional | Body `{code, language: auto/python/javascript/java, filename?, store_code?}` → 202 `{public_id, status: "queued"}`. Validation errors return 422 immediately. Rate limit per hour: guests per IP, users per account (admin settings). |
| GET | `/api/analyses/{public_id}[?ft=<feedback token>]` | optional | `AnalysisStatus` while queued/running/failed, the full **Report** when completed |
| GET | `/api/analyses/{public_id}/pdf` | same | `application/pdf`, `xai-report-<8 chars>.pdf`; 409 before completion |
| POST | `/api/analyses/{public_id}/feedback` | optional | `{rating 1–5, was_helpful, comment? (≤2000), feedback_token?}` → `{feedback_id, feedback_token}` (upsert per user / per guest token) |
| DELETE | `/api/analyses/{public_id}` | owner or admin | 204 (cascades) |

`AnalysisStatus = {public_id, status, stage, stage_label, stage_index, stage_count (11), queue_position, started_at, error_message}`.

Access: guest reports are readable by anyone with the UUID until they expire; reports owned by a user only by
that user or an administrator (others receive 404).

### Report (status `completed`)

Top-level keys: `public_id, status, created_at, completed_at, processing_time_ms, expires_at, owner,
submission, overview, breakdown, findings, improved, transparency, feedback` — exactly the contract of the build
specification, Section 9 (mirrored in `frontend/src/api/types.ts` and validated by `ReportOut` in
`backend/app/schemas.py`). Extra fields: `overview.no_review_message`, `overview.ai_unavailable_message`,
`improved.has_problems`, `transparency.llm_requests`, `transparency.processing_time_ms`,
`transparency.code_storage_note`, `transparency.consistency.reason`.

## Admin (FR16)

| Method | Path | Description |
|---|---|---|
| GET | `/api/admin/users?page=&q=` | users with `is_active`, `last_login_at`, `analysis_count` (20 per page) |
| PATCH | `/api/admin/users/{user_id}` | `{role?, is_active?}` — 400 when demoting/deactivating yourself or removing the last active admin |
| DELETE | `/api/admin/users/{user_id}` | deletes the user and all their data (not yourself, not the last admin) |
| GET | `/api/admin/stats?days=30` | totals, per-day counts, languages, processing times (avg, p90), findings by severity/source, review rate, feedback, tool failures, `llm_usage_today`, `llm_usage_history` |
| GET | `/api/admin/settings` | `[{key, value, default, type, min, max, description, options}]` |
| PUT | `/api/admin/settings` | partial `{key: value}` — validated (types, ranges); 422 on violation; returns the full list |
