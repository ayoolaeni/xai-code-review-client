## What is this study about?

We are evaluating a website that explains source code and points out possible problems (for example security
weaknesses), showing how serious and how certain each problem is. We want to know whether its explanations help
developers understand code and decide whether it is safe to use, compared with a plain AI explanation.

## What will I be asked to do?

The session takes about **30–40 minutes**. You will:

1. Read short code samples (about 20–60 lines each) and the explanation given by one of two tools.
2. For each sample, answer three short questions (what the code does, what problems it has, whether it is safe).
3. Fill in a short questionnaire about the explanations (10 statements) and one about the website's usability
   (10 statements).

You will only work with the prepared code samples. **Do not enter any of your own code.**

## Do I have to take part?

No. Taking part is completely **voluntary**. You may **withdraw at any time**, without giving a reason and
without any consequence. If you withdraw, your answers will be deleted if you ask us to.

## What happens to my data?

* Your answers are recorded under a participant number (e.g. P07), **not your name**.
* This consent form is stored separately from your answers.
* The data are used **only for this project** (the project report and any related academic presentation) and
  are reported only as summaries.
* The data are kept securely and deleted after the project has been assessed.
* The website uses the free tier of the Google Gemini API. Only the prepared samples are sent to it — no
  personal information about you.

## Are there any risks or benefits?

There are no known risks. You may find the explanations of code weaknesses useful for your own work.
